# Independent review and root reproduction

The frozen synthetic evidence and the new metric utility received separate
read-only reviews. Neither reviewer accessed datasets, fitted models, installed
dependencies or edited files.

## Frozen evidence review

The reviewer checked the prototype hash and unchanged raw bytes, manifest and
source metadata, 1,280 unique fixtures in 40 strata, stored constraints, failure
counts, aliases, ROC acceptance counts and original denominators. Analytical
coverage and enrollment-dependence bounds passed. Small independent filter,
spline and unfiltered Pearson probes agreed. The full measurement grid was not
rerun by that reviewer; full per-lag arrays and feature vectors are absent.

Two ROC consequences require the external erratum: floating subtraction marks
the conditional 1/3 toy as interpolated and can mark the audit's exact terminal
1/3 crossing undefined. The stored non-crossing results remain correct. The
reviewer also required superseding the raw README's in-place reset instruction.
Both qualifications appear in the publication; frozen r1 remains unchanged.

## Exact metric review

The independent module reviewer found no blocking defect. In addition to the
68 initial tests, 25,488 synthetic cases independently checked 87,183 policies
and 101,352 calibration selections. Both 1/3 probes, conditional/full EER,
coverage crossings, ties, extrema, malformed inputs and precision boundaries
passed. Pinned Ruff 0.17.1 and ty 0.0.90 passed.

The reviewer noted the terminal-equality case lacked a dedicated persistent
test. Root added that six-claim regression; production logic is unchanged. The
documented JSON Schema was parsed, references checked, representative keys
inspected and strict JSON round trips exercised. A full Draft 2020-12 validator
was unavailable and was not installed; full automated schema validation is not
claimed.

## Root follow-through

Root reproduced the frozen experiment in a new directory using the path-only
relocation helper. All scientific fields, including all 1,280 records and the
preserved old ROC calculations, compared exactly; runtime/provenance fields
were excluded explicitly. [The comparison](portable-replay-comparison.json)
retains both runtimes and source fingerprints. This is same-runtime
reproducibility, not additional independent evidence or a portability guarantee.

Corrected examples use the separately reviewed exact-count utility. Root added
the terminal equality regression, mirrored the utility/evidence to Student B,
and ran the focused validation recorded in this bundle. Mirrored code and
evidence represent the same experiment, not replications.

## Publication review

A separate reviewer reconciled all fixture strata, 19 corrected policy states,
source/inventory hashes, mirrored bytes, 98 local links and replay guard behavior.
The reviewer caught one prose error: terminal rates for accepting every valid
claim had been assigned to reject-all. Root corrected the description; the
numeric examples and utility were already correct. The published reproduction
command now includes all three files in the retained 268-test logs.
